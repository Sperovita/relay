# Agent instructions

This repo uses relay, a file-based handoff convention. Sessions are disposable; the files under `relay/` are the memory.

- **Session start:** follow `relay/process/pickup.md` before doing anything else.
- **Session end, or when the user says wrap / wrap it up / stop here / hand off:** follow `relay/process/wrap.md`.
- **Conventions** (ticket sizing, ADR rules, parallel sessions, naming): `relay/process/conventions.md`.
- **Templates:** `relay/templates/`.

Tools that read this file do not auto-expand references. Open the files above with your read tool when told to.
